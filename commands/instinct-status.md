# Taozi Instinct Status - 本能状态

查看所有已学习的本能模式，包括置信度评分、学习日期和分类统计。

## 执行步骤

### 1. 读取学习记录

```bash
TAOZI_DIR="${TAOZI_HOME:-$HOME/.taozi}"

# 检查目录
ls "$TAOZI_DIR/learned/"

# 统计文件数量
find "$TAOZI_DIR/learned/" -type f | wc -l
```

### 2. 解析每条记录

读取每条学习记录，提取以下信息：
- **主题**: 学习的内容主题
- **类别**: 技术领域分类
- **置信度**: 基于重复次数和使用频率计算
- **学习日期**: 首次学习和最近强化的日期
- **来源**: 从哪个项目/任务中学到的
- **状态**: active / inactive / evolving

### 3. 计算置信度

置信度评分规则：
```
基础分: 50
+ 每重复出现一次: +10（上限 +30）
+ 最近 7 天内有强化: +10
+ 已成功应用 3 次以上: +10
- 超过 30 天未使用: -10
- 与现有记录矛盾: -20

最终分数范围: 0-100
```
