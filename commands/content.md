# 多平台内容创作

根据 `$ARGUMENTS` 生成内容。

---

## 第一步：解析创作意图

### 目标平台

| 用户说 | 平台 | 模式 |
|--------|------|------|
| "小红书"、"种草"、"笔记" | 小红书 | 单平台 |
| "公众号"、"文章"、"长文" | 公众号 | 单平台 |
| "抖音"、"短视频"、"脚本"、"视频号" | 抖音/视频号 | 单平台 |
| "X"、"推特"、"Twitter" | X/推特 | 单平台 |
| "多平台"、"矩阵"、"都要" | 全平台 | 矩阵模式 |
| 未说明 | 小红书 | 单平台（默认） |

### 内容风格

| 用户说 | 风格 |
|--------|------|
| "专业"、"干货"、"权威" | 专业干货 |
| "种草"、"安利"、"推荐" | 种草推荐 |
| "轻松"、"日常"、"随便聊" | 轻松日常 |
| 未说明 | 根据平台自动匹配 |

### 输入来源识别

- 上下文中有研究报告 → 自动提取关键信息作为素材
- 只有主题 → 直接基于主题创作

---

## 第二步：生成内容

### 小红书笔记

```
标题：
<带 emoji，25字以内，参考爆款格式>

正文：
<场景代入开头（3-5行）>

<核心内容，分点列出，每点带 emoji>

<结尾互动号召>

话题标签：
#话题1 #话题2 #话题3（5-8个）

配图建议：
<风格描述，可衔接 /taozi:images>
```

### 公众号文章

```
标题：<30字以内，有悬念或实用感>
副标题：<一句话说清楚读者能获得什么>

引言（1-2段）：
<痛点或背景>

主体（H2 分节，每节300-500字）：
## 第一节
<内容>

## 第二节
<内容>

结尾：
<总结 + 互动引导>

封面建议：<风格描述>
```

### 抖音/视频号脚本

```
视频标题：<20字以内>

分镜脚本：
00:00-00:03  开场钩子（直接说结论 or 提问）
00:03-00:15  展开背景
00:15-00:45  核心内容（2-3个点）
00:45-00:55  总结/行动号召
00:55-01:00  结尾互动

口播文案：
<完整口播稿，语气口语化>

BGM 建议：<情绪/风格>
```

### X/推特

```
主推文（英文为主，附中文，280字以内）：
<简洁有力，带 1-2 个话题标签>

线程（可选）：
2/ <追加推文>
3/ <追加推文>
```

## 附加能力

**标题工厂**（用户说"多给几个标题"时）：
输出 10 个不同角度的标题变体：数字型、对比型、悬念型、情绪型、问题型各 2 个。

**爆款拆解**（用户粘贴一篇内容时）：
分析标题钩子技巧、内容结构套路、互动设计位置，并提炼可复用模板。
