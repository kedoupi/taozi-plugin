# 多平台内容创作

---

## 第一步：解析创作意图

从用户描述中提取三个参数：

### 目标平台

| 用户说 | 平台 | 模式 |
|--------|------|------|
| "小红书"、"种草"、"笔记" | 小红书 | 单平台 |
| "公众号"、"推文"、"文章" | 公众号 | 单平台 |
| "抖音"、"短视频"、"脚本" | 抖音/视频号 | 单平台 |
| "X"、"推特"、"Twitter" | X/推特 | 单平台 |
| "多平台"、"矩阵"、"全部" | 全平台 | 矩阵模式 |
| 未说明 | 小红书 | 单平台（默认） |

### 内容风格

| 用户说 | 风格 |
|--------|------|
| "专业"、"权威"、"报告感" | 专业干货 |
| "种草"、"安利"、"推荐" | 种草推荐 |
| "轻松"、"日常"、"随便聊" | 轻松日常 |
| 未说明 | 根据平台自动匹配（小红书默认种草，公众号默认干货） |

### 输入来源

- **直接主题**：用户给了一个话题 → 直接创作
- **基于研究**：上下文中有研究报告 → 提取关键内容作为素材输入

---

## 第二步：生成内容

主 agent 直接生成内容，无需派子 Agent（纯文本生成，不需要 YouMind API）。

### 各平台输出规范

#### 小红书笔记

```
【标题】
带 emoji 的吸引眼球标题（25字以内），参考爆款格式：
- 「XX合集｜真的太好用了！」
- 「学会这一招，XX直接起飞」
- 「XX避坑指南，我帮你踩过了」

【正文】
- 开头：场景代入 or 痛点引发共鸣（3-5行）
- 中间：核心内容，分点列出，每点带 emoji
- 结尾：行动号召（"你试过吗？评论区聊聊"）

【话题标签】
#话题1 #话题2 #话题3（5-8个，含平台热门标签）

【配图建议】
<说明适合什么风格的配图，可衔接 /taozi:images>
```

#### 公众号文章

```
【标题】
悬念感/实用感标题，30字以内

【副标题/摘要】
一句话说清楚读者能获得什么

【正文结构】
- 引言：1-2段，点出痛点或背景
- 主体：H2 分节，每节300-500字
- 数据/案例：增强可信度
- 结尾：总结 + 互动引导

【封面建议】
<说明封面图的风格和内容>
```

#### 抖音/视频号脚本

```
【视频标题】
搜索友好 + 吸引点击（20字以内）

【分镜脚本】
00:00-00:03 开场钩子（直接说结论 or 提问）
00:03-00:15 展开背景
00:15-00:45 核心内容（分2-3个点）
00:45-00:55 总结/行动号召
00:55-01:00 结尾互动（"关注我，下期讲XX"）

【口播文案】
<完整口播稿，语气自然口语化>

【BGM 建议】
<情绪/风格描述>
```

#### X/推特

```
【主推文】
英文为主（附中文），280字以内
简洁有力，带1-2个话题标签

【线程（可选）】
如需展开，提供2-3条追加推文
```

---

## 矩阵模式

同一话题，并行输出所有平台版本，格式：

```
=== 小红书版 ===
<内容>

=== 公众号版 ===
<内容>

=== 抖音脚本版 ===
<内容>

=== X/推特版 ===
<内容>
```

## 第三步：输出后询问

内容生成完毕后主动询问：
> 需要调整风格或重写某个平台的版本吗？还是要基于这个内容生成配图（`/taozi:images`）？

## 附加能力

### 标题工厂
用户说"给我多几个标题"时，输出 10 个不同角度的标题变体：
- 数字型：「5个XX让你...」
- 对比型：「XX和XX，差距竟然这么大」
- 悬念型：「为什么XX的人都在用这个...」
- 情绪型：「终于找到了！XX真的绝了」
- 问题型：「你还在XX？难怪效果差」

### 爆款拆解
用户粘贴一篇内容时，分析：
- 标题钩子用了什么技巧
- 内容结构是什么套路
- 互动设计在哪里
- 可复用的模板提炼
