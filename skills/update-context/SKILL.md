# Taozi Context Update

## 目标

为一个目录生成或更新长期上下文文档，帮助后续代理快速理解模块职责。

## 文档位置

- Claude 侧优先兼容 `CLAUDE.md`
- Codex 侧优先使用 `AGENTS.md`
- 如果仓库已经明确采用某一种，优先遵循现有模式

## 适用场景

- 新接手模块，需要快速建立目录说明
- 代码结构变化较大，需要更新职责说明
- 用户明确要求“更新上下文”或“补 codemap”

## 更新流程

1. 扫描目标目录的主要文件和子目录
2. 识别职责、依赖、测试入口和风险点
3. 若文档已存在，增量更新，不覆盖手写内容
4. 保持内容短而稳定，不复制实现细节

## 推荐结构

- 模块职责
- 关键文件
- 依赖关系
- 开发注意事项
- 最近变更

## 禁忌

- 不粘贴大段代码
- 不生成会频繁过时的细节
- 不把临时调试过程写进长期上下文
