# Taozi Model Route

## 目标

根据任务复杂度、风险和时效要求，选择合适的模型或子代理组合。

## 路由维度

- 复杂度: 简单 / 中等 / 高
- 风险: 普通 / 高风险 / 安全敏感
- 时效: 实时 / 正常 / 可等待
- 产出类型: 规划 / 实现 / 审查 / 总结

## 建议策略

- 简单查询、格式化、轻量转换: 快速低成本模型
- 常规开发、测试、文档、重构: 平衡型模型
- 架构设计、复杂 debug、安全决策、高风险改动: 高推理模型

## 多代理拆分建议

- 规划代理: 更高推理
- 实现代理: 平衡型
- 审查代理: 视风险提升推理强度
- 总结代理: 可降级

## 决策原则

- 默认不为简单任务动用最高成本模型
- 高风险任务优先保守，不只看速度
- 当一个任务能拆成阶段时，优先分阶段路由而不是全程一个模型

## 输出要求

- 任务评估
- 推荐模型或代理组合
- 推荐理由
- 可接受的降级方案
