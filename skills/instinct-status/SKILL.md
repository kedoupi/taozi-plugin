# Instinct Status

查看所有已学习的本能模式，包括置信度评分、学习日期和分类统计。

## 何时使用

- 想了解当前积累的本能规模和质量
- 判断哪些类别成熟到可以 evolve 为 skill
- 用户要求"查看本能"、"本能状态"

## 执行步骤

### 1. 读取学习记录

```bash
TAOZI_DIR="${TAOZI_HOME:-$HOME/.taozi}"
ls "$TAOZI_DIR/learned/"
find "$TAOZI_DIR/learned/" -type f | wc -l
```

### 2. 解析每条记录

提取：主题、类别、置信度、学习日期、来源、状态（active / inactive / evolving）。

### 3. 置信度评分规则

```
基础分: 50
+ 每重复出现一次: +10（上限 +30）
+ 最近 7 天内有强化: +10
+ 已成功应用 3 次以上: +10
- 超过 30 天未使用: -10
- 与现有记录矛盾: -20

最终分数范围: 0-100
```

### 4. 格式化输出

```markdown
## 本能状态报告

### 总览
- 本能总数 / 高置信度 (>= 80) / 中 (50-79) / 低 (< 50) / 最近 7 天新增

### 本能列表

|---|------|------|--------|---------|---------|------|
| 1 | React 状态管理 | 前端 | 90 | 2025-01-15 | 2025-04-03 | active |

### 分类统计

| 类别 | 数量 | 平均置信度 |
|------|------|-----------|
| 前端 | 5 | 82 |

### 进化建议
- 前端类别记录丰富（5 条），可执行 /taozi:evolve 合并为 Skill

```
