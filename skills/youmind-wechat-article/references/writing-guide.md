# 写作指南

> 本文件是微信公众号文章的核心写作规范。客户专属 playbook.md 优先级高于本文件，但本文件的 de-AI 协议和格式规范始终生效。

---

## 一、根本问题：为什么 AI 写的文章让人读不下去

AI 写作的默认模式是"优等生模式"：结构完整、论点平衡、引用充足、逻辑严密。
这对学术报告是优点，对微信公众号是致命缺陷。

公众号读者不需要全面。他们需要的是：

1. **被击中的感觉** — 看到某句话，心里一颤，想起了某个情境
2. **可以转述的观点** — 周末家庭聚餐时说出来能引发讨论的那句话
3. **带走某种情绪** — 愤怒、希望、好奇、释然、共鸣

AI 的失败点在于：它在优化"准确性"，读者在寻找"共鸣"。这两者不冲突，但要刻意对齐。

---

## 二、原子洞察：写前必须完成的最重要步骤

**定义**：用一句话说出这篇文章存在的理由。这句话必须满足：
- 读者会在饭桌上转述它
- 它不是事实陈述，而是观点或反直觉发现
- 它有争议性，有人会不同意

**测试方法**：把这句话发给朋友，如果朋友的反应是"嗯，对"，它太平庸。如果朋友的反应是"等等，真的吗？" 或 "这倒是，但……"，它是对的。

**写前检查（不完成禁止开始写作）：**

```
我的原子洞察是：__________

如果读者只记住一件事，那件事是：__________

这个观点，谁会不同意？他们的理由是：__________
```

没有通过这个检查的文章，重新构思选题，不要强行动笔。

## 三、"So What"三层法

AI 最常犯的错误是停在第一层。

| 层级 | 描述 | 示例 |
|------|------|------|
| Layer 1 | 表面现象（AI 最擅长） | "年轻人越来越不愿意买房了" |
| Layer 2 | 隐含意义（需要推理） | "买房不再是成年人的身份认同标志" |
| Layer 3 | 可执行或挑衅性观点 | "父母那一代把房子当安全感，我们这代人正在重新定义安全感是什么" |

文章必须抵达 Layer 3，且 Layer 3 要放在显眼位置（副标题、第一段、或小标题）。

## 四、写前思维框架（强制执行，写入草稿顶部，发布时删除）

每篇文章开始前，必须在草稿文件顶部写出以下四项：

```
【读者场景】
这篇文章的理想读者，此刻在哪里？他们在做什么？是通勤刷手机，还是睡前翻公众号？
他们今天发生了什么让他们有动力点进这篇文章？

【情感旅程】
读者打开文章时的情绪：__________
读者读完文章时的情绪：__________
这两个状态之间发生了什么转变？

【核心张力】
这篇文章的内在冲突是什么？（例：想要自由 vs. 需要稳定；想要改变 vs. 害怕失败）
如果没有张力，没有人读下去。

【最强反驳】
理性的读者看到我的核心观点，会提出的最有力反驳是什么？
我在文章里承认了这个反驳了吗？（必须承认，否则显得幼稚）
```

## 五、文章结构规范

### 5.1 开头（前 200 字是生死线）

**绝对禁止的开头方式：**
- "在当今社会……"
- "随着 XX 的发展……"
- "近年来，XX 现象引发了广泛关注……"
- 背景介绍式开头
- 定义解释式开头

**有效的开头方式（选一种）：**

1. **场景锚定法**：把读者放进一个具体的感官场景
   > 示例："周五下午五点半，你盯着电脑屏幕，Slack 消息还在跳，但你的大脑已经关机了。"

2. **颠覆预期法**：说一句读者以为你不会说的话
   > 示例："我要说一件让很多职场博主不高兴的话：努力工作本身没有任何意义。"

3. **直接抛出矛盾**：揭示一个存在于读者生活里但没被命名的矛盾
   > 示例："我们一边羡慕那些'活得通透'的人，一边每天给自己制定更多的计划。"

4. **数据 + 反问**：用一个意外的数字开头，然后问"为什么"
   > 示例："中国有 1400 万注册心理咨询师，但能预约到好咨询师的人说：感觉更难了。"

### 5.2 正文节奏

- 每个小节不超过 400 字
- 每隔 150-200 字插入一个"呼吸点"（一句极短的话，单独成段）
- 论点 → 具体例子 → 感受描述 → 延伸 → 下一论点
- 禁止超过 3 个连续的并列句（这是 AI 的标志性文风）

### 5.3 结尾

结尾不是总结。总结是 AI 的本能，是读者流失的开始。

**有效结尾方式：**

1. **开放性问题**：把一个问题留给读者，让他们带着走
2. **行动召唤（具体的，不是"点赞关注"）**：一件今天就能做的小事
3. **情绪落点**：用一个句子定下基调，让读者带着某种情绪离开
4. **回扣开头**：用一句话呼应开头的场景或问题，形成闭环

**绝对禁止：**
- "总结一下，本文主要讲了……"
- "希望对大家有所帮助"
- "欢迎在评论区分享你的想法"（太通用，没有价值）

## 六、de-AI 协议（4 级，按序执行）

完成初稿后，对照以下 4 级协议逐项检查。

### Level 1：替换结构词

**扫描并替换以下词汇（全文搜索）：**

| AI 常用词 | 替换方向 |
|-----------|----------|
| 首先、其次、最后 | 删掉，直接进入内容；或用更具体的过渡 |
| 总的来说 | 删掉 |
| 值得注意的是 | 删掉，直接说那件值得注意的事 |
| 不可否认 | 删掉 |
| 毋庸置疑 | 删掉 |
| 与此同时 | 改用更具体的连接 |
| 从而 | 多数情况下可删掉，改短句 |
| 有效地、显著地 | 删掉，换成具体数字或例子 |
| 赋能、抓手、闭环、颗粒度 | 禁用，替换为日常语言 |
| 深度融合、协同共赢 | 禁用 |

### Level 2：打破并列排比

**识别方式：** 三个或更多以相同句式开头的句子，或三个并列项的列表。

**处理方式：**
- 选最重要的一项展开，其余的要么删掉，要么变成正文句子
- 把并列改成递进或转折
- 如果非用列表不可，列表项必须不等长、不同开头

**示例：**

AI 原文：
> "这种方式有三个优点：第一，节省时间；第二，提高效率；第三，降低成本。"

de-AI 后：
> "这种方式最实际的好处是省时间——不是那种说说而已的省，是每周能多出半天的那种。效率和成本是副产品，大多数人最在意的还是时间。"

### Level 3：注入认知不完美

AI 的默认姿态是全知的、自信的、完整的。真实的人类作者有以下特征：
- 自我怀疑：对自己的某个结论不确定
- 矛盾：同时持有两个不完全兼容的观点
- 没答案的问题：承认某件事自己也没想清楚

**操作方式：** 在文章中找一处加入"不确定声音"，例如：

> "说实话，我写到这里也没把握。这个结论成立的前提是……如果前提不成立，我说的这些可能都是废话。"

> "我有时候觉得 A，有时候又觉得 B，这两个想法在我脑子里共存了很久，我也没找到哪个更对。"

> "这个问题我问过很多人，没有人给出让我满意的答案。包括我自己。"

### Level 4：节奏变化

**识别问题：** 全文句子长度均匀（80-120字的句子反复出现），读起来像在朗读报告。

**处理方式：** 主动制造节奏断层。

```
长句（50-80字，用来建立语境和推进论证）
↓
中句（20-40字，用来点明观点）
↓
短句（5-15字，用来强调）
↓
极短句（1-8字，单独成段，制造停顿）

就这样。
```

极短句至少出现 3 次，分布在文章的不同位置。

## 七、标题规范

### 7.1 字数

- **强制范围：20-28 汉字**（微信显示优化，不含标点）
- 副标题可选，不计入主标题字数

### 7.2 禁用词汇

以下词汇已被过度使用，禁止出现在标题中：
- 最全、颠覆、赋能、干货、硬核
- 必看、收藏、建议所有人
- 爆了、炸了、刷屏了
- XX岁的你、写给XX人
- 看完这篇文章你就懂了

### 7.3 有效标题结构（优先选用）

| 结构 | 示例 |
|------|------|
| 数字 + 具体场景 | "入职 3 年，我才明白为什么开会总是说不上话" |
| 反问 + 反直觉 | "为什么越努力的人，越容易感到空虚？" |
| 对比 + 核心观点 | "同样是 35 岁，有人开始走下坡路，有人才刚刚起步" |
| 事件 + 洞察 | "那个总被说'太敏感'的同事离职后，我才想明白一件事" |
| 场景 + 结论 | "周末刷完一天手机，为什么比上班还累？" |

### 7.4 标题自测

写完标题后问自己：
1. 这个标题，我的目标读者会转发给谁？
2. 读者看到标题后的第一个反应是什么？（好奇、共鸣、还是"emmm"？）
3. 这个标题承诺了什么？文章兑现了吗？

---

## 八、摘要规范

- **字数限制：≤54 汉字，≤120 UTF-8 字节**（微信接口硬限制）
- 摘要不重复标题（读者已经看到标题了）
- 摘要要有"钩子"，让读者想点进去
- 摘要可以是文章中最有力的一句话
- 不要用"本文探讨……"或"文章将介绍……"

**摘要写法模板（选一种）：**

1. **悬念式**："你以为这是效率问题，其实是认知问题——而且大多数人搞反了方向。"
2. **共鸣式**："有些话，你说不出口，但你心里一直知道。"
3. **数据冲击式**："1000 个人做了同一件事，只有 3 个人得到了他们想要的结果。这 3 个人做对了什么？"

---

## 九、关键词使用规范

- 核心关键词在标题中出现 1 次
- 核心关键词在正文首段出现 1 次
- 全文关键词密度：1%-3%（不要刻意堆砌）
- 优先使用读者在微信搜索时会用的自然语言，而非 SEO 优化词

---

## 十、写作自检清单

完稿后逐项对照：

- [ ] 我能用一句话说出这篇文章的原子洞察
- [ ] 开头前 200 字没有背景铺垫
- [ ] 全文不含 Level 1 禁用结构词
- [ ] 没有超过 3 个连续并列句
- [ ] 文章中有至少 1 处自我怀疑或未解答的问题
- [ ] 有至少 3 个极短句（单独成段）
- [ ] 标题字数在 20-28 字之间
- [ ] 摘要不超过 54 汉字
- [ ] 结尾没有"总结一下"
- [ ] 读完后，我自己觉得值得转发吗？

最后一条是最重要的。如果你自己都不想转发，读者不会转发。
