# Taozi Multi Agent

## 目标

把复杂任务拆成可并行执行的子任务，并给每个子任务匹配合适的专业代理。

## 何时使用

- 任务跨多个模块或层次
- 既要实现，又要测试、审查、文档同步
- 用户明确要求并行、多代理、分工协作

## 拆分原则

- 子任务要有清晰输入和输出
- 写入范围尽量互不重叠
- 阻塞主路径的工作不要轻易外包
- 审查和验证任务适合并行跟进

## 推荐流程

1. 定义最终目标和验收标准
2. 识别必须串行的关键路径
3. 找出可以并行的探索、实现、验证任务
4. 指定每个子任务的责任范围
5. 汇总结果，做最后集成

## 常见分工

- `architect`: 方案和边界
- `fullstack-developer`: 核心实现
- `testing-engineer` 或 `tdd-guide`: 测试
- `code-reviewer` / `security-reviewer`: 审查
- `doc-updater`: 文档同步

## 输出要求

- 子任务列表
- 依赖关系
- 并行组划分
- 每个代理的预期产物
- 汇总和验收方式
