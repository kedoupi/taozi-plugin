# Taozi Learning

## 目标

把一次性的解决过程整理成可复用的长期经验，而不是只停留在当前会话。

## 适用场景

- 刚解决一个难 bug 或完成一段复杂实现
- 发现新的工程模式、调试路径、验证套路
- 用户要求总结、沉淀、记录经验、保存检查点

## 可沉淀内容

- 问题模式和识别信号
- 有效的排查顺序
- 可靠的实现模板
- 常见坑和规避方式
- 还未完全验证的假设

## 保存原则

- 结论要能脱离当前会话单独理解
- 把“问题 -> 方案 -> 约束 -> 验证”写完整
- 没验证透的内容要明确降低置信度

## Taozi 数据目录

- `$TAOZI_HOME` 优先
- 默认 `~/.taozi`
- 兼容旧的 `~/.claude/taozi`

## 输出建议

- 简短模式名
- 适用场景
- 核心步骤
- 风险和前提
- 复用建议
