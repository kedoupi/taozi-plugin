# Taozi Plan

## 何时使用

- 功能需求较大，不能一步直接改完
- 涉及多个模块、跨层变更或技术选型
- 用户明确要求方案、计划、拆分任务

## 规划步骤

1. 用一句话明确目标和完成标准
2. 识别受影响模块、依赖和外部约束
3. 拆分为可执行步骤，标注依赖关系
4. 提前列出风险点、未知项和验证方案

## 计划标准

- 步骤要能直接执行，不写空泛动作
- 优先从低风险、能建立反馈的步骤开始
- 明确哪些可以并行，哪些必须串行
- 给出最小可行版本，而不是一次做满

## 输出格式

- 目标
- 约束
- 执行步骤
- 风险与验证
