# 封面图生成指南

> 本文件供 pipeline Step 6 使用。根据文章标题和 style.yaml 的 cover_style 字段，构建传入 YouMind 的图像生成 prompt。

---

## 1. 微信公众号封面规范

| 用途 | 尺寸 | 宽高比 | 格式 | 大小限制 |
|------|------|--------|------|----------|
| 头条文章封面（首图） | 900×383 px | ~2.35:1 | jpg | ≤1MB |

**生成策略：** 指定 `aspectRatio: "16:9"`，脚本上传时自动中心裁切到 900×383。quality 使用 `"standard"`（高质量图片文件通常 1-3 MB，避免超时）。

---

## 2. 核心设计原则：海报风格

微信封面 = **背景视觉 + 大字标题**，类似杂志封面或新闻海报。

**必须包含：**
- 文章标题作为大字排印在画面中，中文粗体，清晰可读
- 标题占画面 30-50% 高度，视觉权重最高
- 背景图/色块与标题形成对比（深底白字 或 浅底深字）

**禁止：**
- 纯插画无文字（这是图标，不是封面）
- 文字太小读不清
- 背景太花导致文字糊在一起

## 3. Prompt 构建模板

### 构建顺序

```
[版式描述] + [标题文字] + [背景/视觉] + [色调] + [技术规范]
```

**技术规范（固定追加）：**
```
16:9 横版，微信公众号封面海报，中文大字清晰可读，高清商业品质
```

### 示例结构

```
新闻海报风格，大字标题「{文章标题}」居中或左对齐，
粗体中文，白色文字叠加在[深色/渐变]背景上，
背景是[与文章主题相关的视觉：场景/图案/纹理/色块]，
[色调描述]，专业排版感，
16:9 横版，微信公众号封面海报，中文大字清晰可读，高清商业品质
```

## 5. 子 Agent 执行指令

在 Step 6 构建 prompt 时：

1. 从文章标题中提取 **8-15 字的封面大标题**（可以比正文标题更简短有力）
2. 根据文章行业/主题选择风格（tech / business / opinion / minimal）
3. 将封面大标题嵌入 prompt 的 `「{标题}」` 位置
4. 检查 `wechat-articles/character.md` 是否存在：
   - **存在** → 读取文件，提取角色描述追加到 prompt（见第 6 节）
   - **不存在** → 不追加，AI 自由发挥视觉元素
5. 使用 `quality: "medium"` 生成（文件大小可控，1-3MB）

**YouMind 调用参数：**
```json
{
  "aspectRatio": "16:9",
  "quality": "medium",
  "model": "gemini-3-pro-image-preview"
}
```

## 6. character.md 角色嵌入规则

`wechat-articles/character.md` 是可选文件，定义每张封面都应出现的固定 IP 角色。模板见 `references/character-template.md`。

### 有角色文件时的 prompt 构建

读取 `wechat-articles/character.md`，从各章节提取关键信息，拼接成一句角色描述，追加到封面 prompt 末尾：

```
画面中包含固定角色：{从 character.md 提炼的角色一句话描述}，{位置偏好}，角色与标题文字共存，不遮挡主标题
```

**提炼规则：** 将 character.md 的"基础外形 + 标志性元素 + 画风 + 位置偏好"压缩成 30-50 字的描述。

**完整示例（卡通熊猫角色）：**
```
新闻海报风格，大字标题「AI工具替代了什么」白色粗体居左，
深蓝渐变背景，右侧科技光效，
画面中包含固定角色：戴圆框眼镜的卡通熊猫，穿黑色卫衣，手持平板电脑，卡通扁平风，站在右下角，
角色与标题共存，不遮挡主标题，
16:9 横版，微信公众号封面海报，中文大字清晰可读，高清商业品质
```

---

## 7. 注意事项

- AI 生成中文文字有时会写错字或变形，**发布前务必预览封面**
- 若文字渲染不佳，可重新生成（每次结果不同）
- 封面大标题不必和文章标题完全一致，可提炼为更短的爆点句
- `cover_character` 角色描述越详细越稳定；过于简短（如"一只猫"）每次生成差异较大
